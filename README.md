# 🪙 Lucky Plans

**Lucky Plans** is a data science–driven blockchain project focused on discovering and building **profitable strategies** from blockchain data.

The core idea: **earn through data intelligence** — analyzing on-chain behavior, building actionable insights, and turning them into automated trading opportunities.

---

## 🌟 Overview

Lucky Plans is a collection of multiple **sub-projects (Lucky Plans)**, each designed to explore a unique earning mechanism in DeFi and blockchain analytics.

Our first mission is to analyze trader performance on perpetual trading platforms and build **copy trading systems** based on real, verifiable data.

---

## 🚀 Current Focus: Perp Leaderboards & Copy Trading Bots

### 🎯 Goals
- Build **leaderboards** for traders across **GNS**, **GMX**, and **Avantis**.
- Develop **efficient copy trading bots** using leaderboard insights.
- Generate **on-chain analytics and performance metrics** for alpha discovery.

### 🧱 Planned Features
- Fetch and index public trading data from supported protocols.
- Rank traders by multiple performance metrics (PnL%, win rate, Sharpe ratio).
- Expose leaderboard and analytics through a **GraphQL API**.
- Build automated bots that replicate top trader strategies with adjustable risk.

---

## 🔮 Future Lucky Plans

- 📈 Develop in-house **data-driven trading strategies** using backtesting and simulation.
- 🧠 Integrate **machine learning** models for signal prediction and anomaly detection.
- 🔄 Expand to more DeFi and on-chain protocols.
- ⚙️ Automate portfolio rebalancing and performance monitoring.
